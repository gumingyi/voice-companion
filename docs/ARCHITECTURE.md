# 架构（0.5）

Qt主线程负责界面，全局快捷键线程使用RegisterHotKey。音频使用PyAudioWPatch回调采集WASAPI或麦克风，转为16kHz单声道PCM；有界队列把音频送到独立Vosk线程，每个来源持有自己的增量解码会话。用户结束时排入尾句结束标记，队列确认后才生成一次请求；部分结果只替换临时显示，不逐条提交。

Controller的独立asyncio线程执行模型SSE请求并持有可复用HTTPX连接池。首字立即推送，后续快照最多约20次/秒合并；Qt增量追加答案且只在历史结构变化时重建列表。请求携带分阶段计时，连接错误与明确服务错误有限重试，已接受请求的超时不盲目重发。

FastAPI/Uvicorn伴侣服务只推送文字白名单，随机单次邀请兑换HttpOnly/SameSite Cookie；限制Host/Origin，断线恢复最近30条快照。绑定实际私网IPv4，不监听0.0.0.0；防火墙规则仅通过用户点击和UAC授权添加。HTTP不加密，限可信局域网。

Windows凭据管理器保存Key，普通JSON保存配置与用户主动录入的背景资料。音频不持久化；问答历史默认关闭，可选本机明文保存。日志仅记录固定事件。退出停止采集、注销快捷键、关闭手机服务、取消网络任务并释放连接池。

供应商适配器当前实现OpenAI Chat Completions协议，真实优先验证DeepSeek；没有伪装实现其他原生协议。语音识别当前为Vosk，术语替换是字面替换而非声学热词；混合模式去重不是回声消除。没有OCR、RAG检索、云ASR、跨公网连接或本地大模型训练。

0.5展示层样式独立在theme.py，使用原生Qt控件和缓存SVG线性图标；没有增加后台动画或网络素材。窗口重排、等待状态、中文表单和移动页面CSS不改变音频、供应商和配对边界。

项目最初从报告/PPT资料目录中新建为独立voice_assistant子目录，原资料保留。当前构建位于dist-v0.5，release只保留当前源码与便携包，build由打包脚本按需重建。
