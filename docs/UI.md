# 0.5界面更新与检查

本轮调整展示层，保留原有功能、快捷键、模型、模板、资料和凭据。

- 主界面采用灰白背景和青绿强调色，问题编辑与历史在左、参考答案在右，底部集中开始/结束收音及电平显示。
- 顶部状态显示收音、生成、暂停或异常，主要操作与次要操作有清晰层级。空白和等待阶段提供说明。
- 模型、模板、资料可在顶部直接切换；快速模式及启用资料保留。常用复制、重新生成、停止和字号调整仍可用。
- 历史列表以问题和完成状态显示，悬停可看完整问题，缩放后保持所选记录可见；不在每个流式片段重建列表。
- 设置统一浅色表单、选项卡、复选框和中文保存/取消，数值输入和下拉箭头使用本地SVG。
- 手机端同步浅色、青绿配色与更适合阅读的留白，WebSocket、配对、Cookie与断线重连逻辑不变。

## 验证

运行 `.venv/Scripts/python scripts/preview_ui.py` 生成原生Qt截图。明确的布局夹具未请求模型、未采音频、未读取真实凭据。源码 `docs/verification/ui` 包含空白、答案、紧凑、最小、宽窗口、模型设置和音频设置7张截图，以及layout_report.json。

实际检查尺寸：1180×780、980×680、960×660和1440×894（宽窗口请求900高，由当前桌面可用区域限制为894）。收音按钮、问题区、答案区与模型/模板/资料控件均位于内容边界内，长文本通过滚动查看。

`scripts/verify_mobile_browser.py --lan` 重新验证了本机实际局域网IP上的390×844移动页面，配对、增量文字、重连、刷新恢复、清空显示和解除配对均通过；仍不能替代实体手机过防火墙验证。

49项原有功能测试通过。`scripts/verify_streaming_windows.py` 复验真实WASAPI、Vosk实时转写和Qt结束收音自动提交路径；模型服务是明确的本地测试夹具。没有为了外观额外请求付费模型。

图标随便携包放在_internal/assistant_app/assets，exe自检包括ui_assets_present。新包验证后清理旧版，只保留最新程序和源码包。
